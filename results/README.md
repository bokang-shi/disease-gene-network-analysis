# Results

This directory contains lightweight result summaries suitable for GitHub.

- `tcga_degs/`: compact TCGA DEG run status and sample availability summaries.
- `tcga_mesh/`: TCGA-mapped MeSH GRN summary tables, network statistics, PageRank top genes, and PCA/UMAP coordinates.
- `single_disease_reproduction/`: compact outputs from single-disease Fig. 3 reproductions.

Large generated matrices, per-project DEG tables, raw count files, and intermediate Parquet files are omitted. See the root README for the workflow used to regenerate them.
